# KSE Hub · Документи

Фронтенд для працівника відділу ЄДЕБО та Ліцензування КШЕ: розділи з Google Drive, документи з типом оновлення і статусом, фільтр за типом, вкладка «Дедлайни».
Дизайн повторює KSE Hub (hub.kse.today): шрифти DM Sans і Space Grotesk, палітра DaisyUI-теми KSE, сайдбар 256px, картки й бейджі з радіусом 20px, світла й темна тема.

## Запуск

Статичний сайт без збірки й залежностей:

```bash
python3 -m http.server 5180
```

Потім відкрийте http://127.0.0.1:5180

## Сторінки

| Маршрут | Що показує |
|---|---|
| `#/` | Огляд: лічильники, 9 розділів, найближчі строки, проблеми з публікацією |
| `#/section/<id>` | Документи розділу: фільтр Усі / Регулярні / Стихійні / Змішані / Не застосовується, пошук, статус, відповідальний, наступне оновлення, посилання на папку в Drive |
| `#/section/all` | Усі 57 документів (сюди веде пошук у сайдбарі, Enter або ⌘K) |
| `#/deadlines` | Регулярні документи, що потребують оновлення: строк ≤ 90 днів, позначка «Застарілий» або «Посилання не працює». Нижче календар і документи без строку |

## Дані — `data.js`

Знімок із Drive станом на 16.11.2026:
- **Розділи й документи** беруться з `Процеси → ЄДЕБО та Ліцензування → Оновлення публічної інформації → Документи`. Тип документа — з назви його папки (`[Регулярний]` і т. д.).
- **Актуальність і відповідальні** — з таблиці «Звіт по документах». Документи, яких там немає, мають статус «Не перевірено».
- **Строки** — з листа «Регулярні — строки» таблиці «Періоди оновлення документів КШЕ». Дата `due` — останній день вікна «Найближче оновлення». Регулярні документи без рядка в цьому листі мають позначку «Строк уточнюється».
- `TODAY` у `data.js` — дата, від якої рахуються дні до дедлайну. Для живого режиму замініть її на `new Date()`.

Папки документів у Drive поки порожні, тому кнопка «Drive» відкриває папку документа.
